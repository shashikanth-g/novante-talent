## 📖 Project Overview

**Novante Talent** is a premium talent management and casting platform developed for an early-stage talent management startup.

The platform was designed around a modern editorial aesthetic inspired by luxury fashion, creative agencies, and contemporary digital experiences.

The website focuses on presenting talent professionally while providing dedicated experiences for:

- Talent discovery
- Talent profiles
- Talent management
- Model development
- Casting enquiries
- Brand enquiries
- Talent applications
- Company information
- Professional standards and transparency

The goal was to create a digital presence that feels **premium, cinematic, minimal, and trustworthy** rather than following traditional modeling-agency website patterns.

The visual identity was designed around a restrained editorial palette.

| Warm Off-White | `#FAF8F5` | Primary light background |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shashikanth-g/novante-talent.git
cd novante-talent
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The development server will be available at:

```text
http://localhost:5173
```

### 4. Create a production build

```bash
npm run build
```

### 5. Preview the production build

```bash
npm run preview
```
